# Devdatta Kasture - Personal Website

Built with Typescipt, CSS, Javascript, and MDX, this website serves as a creative outlet to highlight my projects, writings and hobbies.

## Features

- **Rustic Design**: Rustic aesthetic interface to create a warm and homey feeling
- **Smooth Animations**: Touch animations to seamlessly navigate between tabs
- **Sections Included**:
  - Home
  - About/Academic background
  - Projects showcase
  - Blog page
  - Contact section with links
  - Page to highlight interests and hobbies
  - Resume for professional oppertunities
